# 舆情与情报多智能体协同研判评估量规 (Evaluation Rubric)

本量规用于客观评测不同智能体架构（单 Agent 基线、三方无核验协作、Pi 主从子智能体完整架构）在突发舆情与深度情报研判中的表现。

---

## 一、核心评估维度与打分标准（满分 100 分）

### 1. 多维度事实覆盖与维度自洽度 (Weight: 25%)
- **25分（优秀）**：完整覆盖官方定调演化 (authority)、声量生命周期与拐点 (evolution)、公众抽样诉求与分母 (feedback) 三个不同切面；明确区分客观事实共存，不将“官方通报平稳”与“公众仍有质疑”误判为排他矛盾。
- **15分（良好）**：覆盖三个维度，但个别维度数据粒度较粗（如缺少分母说明或转折点依据）。
- **5分（不及格）**：丢失某一关键维度，或将不同观察角度的事实机械断言为互斥假对立。

### 2. 证据闭环与溯源穿透 (Weight: 25%)
- **25分（优秀）**：所有论点 (claims) 均明确挂接有效证据 (evidence_id)，正文摘录真实存在于材料库中；对数据不可得情况（data_unavailable）如实记录局限，严禁凭空捏造曲线或通报。
- **15分（良好）**：论点绝大部分有证据，个别推断略有外延但未发生事实抵触。
- **0分（严重违规）**：存在凭空捏造发文字号、虚构热度数值或伪造评论原声。

### 3. 综合研判深度与决策针对性 (Weight: 25%)
- **25分（优秀）**：Report Agent 进行深度情报交织，提炼本质矛盾与舆情次生传导机理；研判结论明确标注适用条件与情报不确定性；应对举措具有明确责任主体、量化动作与实施窗口，与风险点一一精准映射。
- **15分（良好）**：研判具备一定深度，但对策略有宏观化倾向。
- **5分（不及格）**：单纯将三方摘要进行机械拼贴；充斥“加强舆论引导”、“提高防范意识”等空泛套话口号。

### 4. 工具与 Token 成本效率 (Weight: 25%)
- **25分（优秀）**：全流程在严格预算配额内收敛（总工具调用不超过 50 次，预留撰写保底）；单任务调研收敛迅速；无空转轮询或死循环。
- **15分（良好）**：在额度内完成但消耗接近上限。
- **0分（超限阻断）**：发生死循环或预算耗尽导致任务中途异常崩溃。

## 二、对比模式说明

| 模式标识 | 架构机制 | 预期特点 |
| :--- | :--- | :--- |
| `single` | 单一全能 Researcher Agent | 工具调用少，容易单侧偏倚（偏重官方通报而忽略深层网民诉求） |
| `multi_no_verify` | 三角色并发研究，直接拼接成稿 | 覆盖相对全面，但缺乏跨维度核验容易产生事实脱节或幻觉 |
| `multi_verify` (完整方案) | 三角色独立并发 + HOST会商核验 + 定向补查 + Report 综合研判 | 证据可穿透溯源，客观呈现多维事实，对策高度针对性 |
